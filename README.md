# Vinay Kumar N — Portfolio

A modern, animated portfolio website built with React, Vite, and Framer Motion.

## Features

- Dark theme with gradient accents and glassmorphism
- Scroll-triggered animations and staggered reveals
- Active section navigation with smooth scrolling
- Responsive mobile menu
- Contact form with loading and success states

## Quick Start

```bash
cd web-proj
npm install
npm run dev
```
